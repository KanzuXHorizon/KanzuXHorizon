- `contribution-snake.yml` publishes light and dark contribution animations to the `output` branch.
- `profile-quality.yml` tests selection logic and validates live generated output, README references, XML, and accessibility metadata.
- GitHub Actions are pinned to immutable commit SHAs and updated through Dependabot.
